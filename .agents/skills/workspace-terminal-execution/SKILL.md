# Workspace Terminal Execution

## ขอบเขตที่อนุญาต
- อนุญาตให้รันคำสั่ง Terminal สำหรับการพัฒนาโปรเจกต์ภายใน Workspace ได้อัตโนมัติ เช่น การติดตั้งแพ็กเกจ, การ Build, การตรวจ Type, การรัน Test, การจัดการ Git ของโปรเจกต์ และการอัปเดต Graphify
- บน Windows หาก PowerShell ติด ExecutionPolicy สำหรับ `.ps1` ให้เรียกผ่าน `npm.cmd` หรือ `yarn.cmd` แทน

## ข้อห้ามเด็ดขาด
- ห้ามสร้าง แก้ไข ย้าย หรือลบไฟล์ใดๆ ที่อยู่นอกโฟลเดอร์ Workspace
- ห้ามรันคำสั่งที่มีผลกระทบต่อระบบปฏิบัติการหรือไฟล์ส่วนตัวของผู้ใช้นอกโปรเจกต์

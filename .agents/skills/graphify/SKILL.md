# Graphify Knowledge Graph Skill

## แนวทางการใช้งาน
1. ใช้ Knowledge Graph ใน `graphify-out/` (ถ้ามี) เพื่อทำความเข้าใจโครงสร้างความสัมพันธ์ของไฟล์ โมดูล และฟังก์ชันในโปรเจกต์
2. ทุกครั้งหลังแก้ไขโค้ดและ Build ผ่าน ให้ตรวจสอบว่าในเครื่องมีคำสั่ง `graphify` ติดตั้งอยู่หรือไม่
3. หากมี `graphify` ให้รัน `graphify update .` อัตโนมัติเพื่ออัปเดต Knowledge Graph ให้สอดคล้องกับโค้ดล่าสุด
4. หากไม่มี `graphify` ในเครื่อง สามารถข้ามขั้นตอนนี้ได้อย่างปลอดภัยและแจ้งให้ผู้ใช้ทราบหากจำเป็น

# กฎการใช้งาน Knowledge Graph (Graphify)

- หากโปรเจกต์มีโฟลเดอร์ `graphify-out/` ให้ใช้ข้อมูลจาก Knowledge Graph ช่วยทำความเข้าใจโครงสร้างความสัมพันธ์ระหว่างไฟล์ก่อนแก้ไขโค้ดข้ามหลายโมดูล
- หลังจากแก้ไขโค้ดและทดสอบ Build ผ่านเรียบร้อยแล้ว หากในเครื่องมีคำสั่ง `graphify` ติดตั้งอยู่ ให้รัน `graphify update .` เพื่ออัปเดต Knowledge Graph ให้ตรงกับโค้ดล่าสุดเสมอ
- ห้ามแก้ไขไฟล์ภายใน `graphify-out/` ด้วยมือ ให้ปล่อยให้เครื่องมือ `graphify` เป็นผู้สร้างและอัปเดตเท่านั้น
